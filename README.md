# 校园商铺周需求历史样本

> **数据性质：教学用模拟数据。** 原项目的演示场景将本文件称为“教学用模拟历史”。本仓库没有真实商铺交易流水、采集凭证或授权记录，因此不能将这些记录解释为真实经营数据。

## 数据概览

| 项目 | 内容 |
| --- | --- |
| 主数据文件 | [需求历史.csv](./需求历史.csv) |
| 观测粒度 | 每周一条记录；没有商铺、商品或校区标识 |
| 覆盖期间 | 2024-06-03 至 2026-09-28 |
| 记录数 | 122 周（121 周的销量与提前期非空） |
| 字段数 | 8 |
| 编码与格式 | UTF-8 CSV；日期为 `yyyy/M/d`，每周周一 |
| 适用场景 | 导入演示、周需求预测教学、特征工程和数据质量练习 |

本数据只代表**一条未标明商品或商铺身份的周序列**，不能据此比较不同商铺或品类的需求。字段 `units` 是样本中的周销量/数量，不代表已验证的“真实需求”；缺货情形可能使销量低于实际需求。

## 仓库内容

- [数据字典](docs/data_dictionary.md)：字段定义、取值和解释边界。
- [来源与使用限制](docs/provenance.md)：可追溯的项目语境及尚缺少的真实性证据。

## 快速开始

```bash
python scripts/validate.py
python examples/analysis.py
```

脚本从仓库根目录或其他工作目录运行均可。导入原 CampusAIS_Show 项目时，使用根目录的 `需求历史.csv`，保留原有字段名。

## 使用边界

请在论文、演示或模型报告中标注“模拟数据”。当前文件没有可核验的真实来源、商铺或商品 ID，且 2026-09-28 行的 `units` 和 `lead_weeks` 为空。不要把最后一行当作零销量。真实应用前，应接入带授权的交易记录，明确商品、门店、时间和缺货口径，再重新验证。
