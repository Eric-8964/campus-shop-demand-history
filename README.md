# 中山大学商铺周需求历史样本

> **数据来源：中山大学。** 

## 数据概览

| 项目 | 内容 |
| --- | --- |
| 主数据文件 | [需求历史.csv](./需求历史.csv) |
| 观测粒度 | 每周一条记录；没有商铺、商品或校区标识 |
| 覆盖期间 | 2024-06-03 至 2026-09-28 |
| 记录数 | 122 周（121 周的销量与提前期非空） |
| 字段数 | 8 |
| 编码与格式 | UTF-8 CSV；日期为 `yyyy/M/d`，每周周一 |
| 适用场景 | 导入演示、周需求预测模型检验和特征工程 |

本数据只代表**未标明商品或商铺身份的周序列**，不能据此比较不同商铺或品类的需求。字段 `units` 是样本中的周销量/数量，不代表已验证的“真实需求”；缺货情形可能使销量低于实际需求。

## 快速开始

```bash
python scripts/validate.py
python examples/analysis.py
```

脚本从仓库根目录或其他工作目录运行均可。导入原 CampusAIS_Show 项目时，使用根目录的 `需求历史.csv`，保留原有字段名。
