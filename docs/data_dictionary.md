# 数据字典

**表名：** `需求历史.csv`  
**主键候选：** `week_start`（当前文件中唯一；若未来加入多商铺/多商品，需使用复合键）  
**粒度：** 单一未标识序列的周记录。日期均为周一。  
**缺失值：** 空字符串；不能解释为 0。

| 字段 | 类型 | 当前取值/范围 | 含义与注意事项 |
| --- | --- | --- | --- |
| `week_start` | 日期 | 2024/6/3–2026/9/28 | 周开始日期；文件使用 `yyyy/M/d` 格式。 |
| `units` | 非负整数，可空 | 非空记录 9–23 | 当周数量；原项目 UI 将其显示为“销量”。不宜直接称为经过缺货校正的需求量。 |
| `lead_weeks` | 非负数，可空 | 非空记录 1.8–2.1 | 以周计的提前期特征；原文件未说明是计划、实际还是预测值。 |
| `term_start` | 0/1 | 0、1 | 开学相关标记。具体校历、标记规则未提供。 |
| `exam_week` | 0/1 | 0、1 | 考试相关标记；不等于经过核验的官方考试周。 |
| `club_fair` | 0/1 | 0、1 | 招新/社团活动相关标记；具体活动记录未提供。 |
| `is_open` | 0/1 | 全部为 1 | 营业状态标记；本样本没有停业周，不能估计停业效应。 |
| `stockout` | 0/1 | 全部为 0 | 缺货状态标记；本样本没有缺货周，不能估计缺货效应。 |

`term_start`、`exam_week`、`club_fair` 可以同时为 1；文件没有提供互斥约束。未来若增加真实数据，应记录每个标记的来源、生成规则与版本。
