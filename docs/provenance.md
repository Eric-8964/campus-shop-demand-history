# 来源与真实性说明

本仓库的 CSV 来自用户本地 `CampusAIS_Show/examples/需求历史.csv`。该项目的 `scenes.py` 在“机器学习 · 周样本”场景中明确写有“导入教学用模拟历史”（英文为 “Import synthetic weekly history”）。项目的 `entry_ui.py` 指定了这 8 个导入字段。仓库中的 CSV 与上传的样本文件保持相同字段和记录。

因此，本数据集应标为**教学/演示用模拟周序列**。当前没有以下材料：真实交易流水、POS/ERP 导出日志、商铺或商品标识、校历/活动证据、采集时间与责任人、共享授权。这些缺口使“历史真实数据”这一说法无法得到支持。

数据中存在重复的 9、10、11、12 周期及类似的年度事件数值，这与模拟数据语境一致；单凭数值规律不能反推出具体生成算法。仓库不声称数据来自任何真实学校或商户。

## 引用建议

> CampusAIS_Show 教学用模拟周销量数据，`需求历史.csv`，2024-06-03 至 2026-09-28，访问本仓库时注明提交版本。

## 后续接入真实数据的最低记录项

1. 数据提供方和可公开使用的授权。
2. 门店、商品、时间粒度和匿名化方式。
3. 销量、退货、缺货及营业状态的业务定义。
4. 提取时间、原始系统、转换脚本与校验日志。
5. 版本号、变更记录和隐私审查结果。

在这些信息齐全前，请勿将本仓库数据描述成真实交易数据库。
