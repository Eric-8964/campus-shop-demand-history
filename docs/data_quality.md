## 分析风险

- 本表没有 `shop_id` 或 `product_id`。不能推断“各项商铺”的横截面差异。
- `is_open`、`stockout` 无变化；把它们作为模型特征不会提供样本内区分信息。
- 周销量不一定等于潜在需求。当前 `stockout` 全为 0，但该标记缺少原始库存证据。
- 校历标记的来源未记录；不要将其当作真实学校日历。
- 周期和事件数值具有规则性，应按教学模拟数据解释；随机划分训练/测试集会高估时序预测表现。
- 2026-09-28 的空目标值应排除在训练与评估之外；预测时可保留为待预测周。

## 可复核流程

运行 `python scripts/validate.py`。脚本对表头、日期、唯一性、周间隔、字段类型、布尔取值及缺失进行检查，并输出概要。它验证文件结构与内部一致性，不能证明交易真实性。
